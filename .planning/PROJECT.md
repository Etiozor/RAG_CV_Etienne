# CV Chatbot

## What This Is

A RAG-powered chatbot accessible via QR code (on paper CV or PDF) that allows recruiters to ask questions about Étienne's professional profile. The bot responds in natural language based on real source documents (mandates, CV, skills) through a RAG pipeline. Deployed on HuggingFace Spaces for free, stable public URL.

## Core Value

Recruiters can instantly get accurate, contextual answers about the candidate's experience and skills — without the candidate being present.

- Multi-candidate support — this is single-candidate only
- User authentication — public access via QR code
- Analytics/tracking of recruiter interactions — privacy first
- Real-time document updates — index is generated once at deploy time

## Context

**Candidate:** Étienne, senior BI analyst

**Source documents (ready):**
- `cv.pdf` — formal CV
- `mandats.md` — project mandates and experiences
- `competences.md` — technical and soft skills

**Target users:** Recruiters scanning QR code from paper/PDF CV

**Language:** French primary, English fallback based on recruiter input

## Constraints

- **LLM**: Claude Haiku via Anthropic API — economic, excellent French support
- **Embeddings**: OpenAI `text-embedding-3-small` — economic, performant, multilingual
- **Vector Store**: ChromaDB — local, no server to manage, must be included in HF Spaces deployment
- **UI**: Chainlit — turnkey chatbot UI, clean, deployable
- **Deployment**: HuggingFace Spaces — free, stable public URL for QR code
- **Language**: Python 3.11+
- **API Keys**: Must be stored in `.env`, never hardcoded; configured as secrets on HF Spaces

## Architecture

```
/docs               <- Source documents (CV, mandates, skills)
   ├── cv.pdf
   ├── mandats.md
   └── competences.md
        |
/indexer.py         <- One-shot script: chunking + embeddings + ChromaDB storage
        |
/chroma_db/         <- Vector index persisted locally (gitignore but deployed)
        |
/app.py             <- Chainlit application
                       - Receives recruiter question
                       - Retrieval from ChromaDB (top-k relevant chunks)
                       - Builds prompt with RAG context
                       - Calls Claude Haiku via Anthropic API
                       - Returns streaming response
```
