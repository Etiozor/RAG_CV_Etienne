Create rag.py module per 02-RESEARCH.md patterns and locked decisions D-01 through D-06.

Configuration constants (MUST match indexer.py exactly):
- CHROMA_DIR = "./chroma_db"
- COLLECTION_NAME = "cv_documents"
- EMBEDDING_MODEL = "text-embedding-3-small"
- DEFAULT_K = 5 (per D-02)

SYSTEM_PROMPT (per D-03, D-04, D-06):
- French language with bilingual instruction per D-06
- Third-person: "Parle d'Etienne a la troisieme personne" per D-03
- Grounding: "Si le CONTEXTE ne contient pas l'information demandee, reponds: 'Je n'ai pas cette information dans les documents disponibles.'" per D-04
- Prohibition: "N'utilise JAMAIS tes connaissances generales pour completer le CONTEXTE"
- Language matching: "Reponds dans la meme langue que la question"
- Include {context} and {question} placeholders

_get_vectorstore() internal function:
- Check OPENAI_API_KEY exists, raise ValueError if missing
- Check CHROMA_DIR exists, raise FileNotFoundError if missing
- Initialize OpenAIEmbeddings with EMBEDDING_MODEL
- Return Chroma with persist_directory, collection_name, embedding_function

retrieve(question: str, k: int = DEFAULT_K) -> list[Document]:
- Call _get_vectorstore()
- Create retriever via vectorstore.as_retriever(search_kwargs={"k": k})
- Return retriever.invoke(question)

build_prompt(question: str, chunks: list[Document]) -> str:
- If chunks empty, context = "Aucun document pertinent trouve."
- Else format each chunk with source metadata: "[Source N: filename]\ncontent"
- Use Path().name to extract filename from source metadata
- Return SYSTEM_PROMPT.format(context=context, question=question)

CLI support via if __name__ == "__main__":
- Accept question from sys.argv[1:]
- Call retrieve() and display chunk count and previews
- Call build_prompt() and display the full prompt
- Handle errors gracefully with sys.exit(1)

Imports needed: os, sys, pathlib.Path, dotenv.load_dotenv, langchain_community.vectorstores.Chroma, langchain_openai.OpenAIEmbeddings, langchain.schema.Document
