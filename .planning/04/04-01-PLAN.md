### Task 1: Create Dockerfile
**File:** Dockerfile (new)
**Action:** Create production Dockerfile for HuggingFace Spaces

**Implementation:**
```dockerfile
# HuggingFace Spaces Docker deployment
# Source: https://huggingface.co/docs/hub/spaces-sdks-docker
FROM python:3.11-slim

# Create non-root user (HF Spaces runs as UID 1000)
RUN useradd -m -u 1000 user
USER user

# Environment setup
ENV HOME=/home/user \
    PATH=/home/user/.local/bin:$PATH \
    PYTHONUNBUFFERED=1

WORKDIR $HOME/app

# Dependencies first for Docker layer caching
COPY --chown=user requirements.txt .
RUN pip install --no-cache-dir --upgrade pip && \
    pip install --no-cache-dir -r requirements.txt

# Application code
COPY --chown=user app.py rag.py indexer.py chainlit.md ./
COPY --chown=user .chainlit ./.chainlit

# Pre-indexed vector store (must be included for RAG)
COPY --chown=user chroma_db ./chroma_db

# Expose HuggingFace Spaces port
EXPOSE 7860

# Production Chainlit command
# -h: headless mode (no browser open)
# --host 0.0.0.0: accept external connections
# --port 7860: HF Spaces default port
CMD ["chainlit", "run", "app.py", "-h", "--host", "0.0.0.0", "--port", "7860"]
```

# CV Chatbot - Etienne Lepironnec

An AI assistant that answers recruiter questions about Etienne's professional profile using RAG (Retrieval-Augmented Generation).

## Features

- Natural language Q&A about experience, skills, and projects
- French and English support (auto-detects language)
- Source-grounded responses (no hallucination)
- Streaming responses for real-time feedback

## Usage

Simply ask questions like:
- "Quelle est l'experience d'Etienne en data engineering?"
- "What are Etienne's technical skills?"
- "Quelles sont ses missions recentes?"

## Technology Stack

- **LLM:** Claude Sonnet (Anthropic API)
- **Embeddings:** OpenAI text-embedding-3-small
- **Vector Store:** ChromaDB
- **UI:** Chainlit
- **Deployment:** HuggingFace Spaces (Docker)

## Local Development

### Prerequisites
- Python 3.11+
- OpenAI API key
- Anthropic API key

### Setup

1. Clone the repository:
```bash
git clone https://github.com/<username>/cv-chatbot.git
cd cv-chatbot
```

2. Create virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Configure environment:
```bash
cp .env.example .env
# Edit .env with your API keys
```

5. Index documents (if needed):
```bash
python indexer.py
```

6. Run the application:
```bash
chainlit run app.py
```

## Deployment

### HuggingFace Spaces

1. Create a new Space at huggingface.co/new-space
2. Select "Docker" as the SDK
3. Clone the Space and copy project files
4. Configure secrets in Space Settings:
   - `ANTHROPIC_API_KEY`
   - `OPENAI_API_KEY`
5. Push to deploy

### Local Docker

```bash
# Build
docker build -t cv-chatbot .

# Run (with API keys)
docker run -p 7860:7860 \
  -e ANTHROPIC_API_KEY="your-key" \
  -e OPENAI_API_KEY="your-key" \
  cv-chatbot
```

### Task 4: Deploy to HuggingFace Spaces
**Action:** Create Space and push code

**Steps:**

1. Create HuggingFace account (if needed): https://huggingface.co/join

2. Create new Space:
   - Go to https://huggingface.co/new-space
   - Name: `cv-chatbot-etienne` (or similar)
   - License: Choose appropriate
   - SDK: **Docker**
   - Hardware: CPU Basic (free)

3. Clone the Space:
```bash
git clone https://huggingface.co/spaces/<username>/cv-chatbot-etienne
cd cv-chatbot-etienne
```

4. Copy project files (including chroma_db!):
```bash
cp -r ../Projet\ CV\ -\ RAG/app.py .
cp -r ../Projet\ CV\ -\ RAG/rag.py .
cp -r ../Projet\ CV\ -\ RAG/indexer.py .
cp -r ../Projet\ CV\ -\ RAG/chainlit.md .
cp -r ../Projet\ CV\ -\ RAG/requirements.txt .
cp -r ../Projet\ CV\ -\ RAG/Dockerfile .
cp -r ../Projet\ CV\ -\ RAG/README.md .
cp -r ../Projet\ CV\ -\ RAG/.chainlit .
cp -r ../Projet\ CV\ -\ RAG/chroma_db .
```

5. Push to HuggingFace:
```bash
git add .
git commit -m "Initial deployment"
git push
```

6. Wait for build (~2-5 minutes)

**Verification:**
- Space status shows "Running"
- URL `https://<username>-cv-chatbot-etienne.hf.space` loads

**Done:** Space deployed and accessible
